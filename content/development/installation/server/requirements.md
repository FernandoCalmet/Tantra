# Server Requirements

## Hardware Requirements

### Minimum Specifications
- **CPU**: Dual-core 2.0 GHz
- **RAM**: 4 GB
- **Storage**: 50 GB HDD
- **Network**: 100 Mbps connection

### Recommended Specifications
- **CPU**: Quad-core 3.0 GHz or higher
- **RAM**: 8 GB or more
- **Storage**: 100 GB SSD
- **Network**: 1 Gbps dedicated connection

## Software Requirements

### Operating System
- Windows Server 2019 (recommended)
- Windows Server 2016 (supported)
- Windows 10/11 Pro (development only)

### Database
- SQL Server 2019 (recommended)
- SQL Server 2017 (supported)

### Runtime Requirements
- .NET Framework 4.8
- Visual C++ 2015-2022 Redistributable
- DirectX 9.0c

## Network Configuration

### Required Ports
- **Game Server**: 7200-7210 (TCP/UDP)
- **Database**: 1433 (TCP)
- **Web Services**: 80, 443 (TCP)

### Firewall Settings
Configure Windows Firewall to allow inbound connections on the required ports.
